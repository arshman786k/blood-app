## 1. Introduction

### 1.1 Purpose
The Blood Group & Donation Management Application is designed to connect blood donors with recipients, manage blood donation records, and facilitate emergency blood requests through an intuitive mobile platform.

### 1.2 Key Features
- **User Authentication**: Secure login and registration system
- **Profile Management**: Manage personal and medical information
- **Blood Test Records**: Upload and track blood test results
- **Donor Mapping**: Find nearby blood donors on an interactive map
- **History Tracking**: View donation and request history
- **Admin Dashboard**: Comprehensive user and system management

### 1.3 System Requirements
- **Operating System**: iOS 13.0+ or Android 8.0+
- **Storage**: Minimum 100MB free space
- **Internet Connection**: Required for full functionality
- **Camera**: Optional (for profile pictures and document uploads)

## 3. User Registration & Login

### 3.1 Creating a New Account

**Step-by-step Guide:**

1. **Navigate to Sign Up**
   - Launch the app
   - Tap "Sign Up" on the welcome screen

2. **Enter Personal Information**
   - Full Name
   - Email Address
   - Phone Number
   - Date of Birth
   - Gender

3. **Medical Information**
   - Blood Group (A+, A-, B+, B-, AB+, AB-, O+, O-)
   - Weight (in kg)
   - Any medical conditions (optional)

4. **Location Information**
   - Allow location access when prompted
   - Or manually enter your city/region

5. **Create Password**
   - Minimum 8 characters
   - Must include: uppercase, lowercase, number, special character
   - Confirm password

6. **Agree to Terms**
   - Read Terms & Conditions
   - Read Privacy Policy
   - Check the agreement box

7. **Verification**
   - Enter verification code sent to your email
   - Tap "Verify" to complete registration

### 3.2 Logging In

**Step-by-step Guide:**

1. Open the app
2. Tap "Login"
3. Enter your registered email address
4. Enter your password
5. Tap "Login" button

**Login Options:**
- Email & Password
- Remember Me (checkbox)
- Biometric Authentication (Face ID/Fingerprint) - if enabled

### 3.3 Forgot Password

1. Tap "Forgot Password?" on login screen
2. Enter your registered email address
3. Check your email for reset link
4. Click the link in the email
5. Enter new password
6. Confirm new password
7. Tap "Reset Password"

## 5. Profile Management

### 5.1 Viewing Your Profile

1. Tap the **Profile** icon in the bottom navigation
2. Your profile displays:
   - Profile picture
   - Name and contact information
   - Blood group
   - Donation statistics
   - Verification status

### 5.2 Editing Profile Information

1. Navigate to Profile
2. Tap "Edit Profile" button
3. Modify any of the following:
   - Profile picture (tap to upload new photo)
   - Full name
   - Phone number
   - Email address (requires verification)
   - Location/Address
   - Emergency contact information

4. Tap "Save Changes"

### 5.3 Medical Information

**Updating Medical Details:**
1. Go to Profile → Medical Information
2. Update:
   - Blood group (requires verification)
   - Weight
   - Allergies
   - Current medications
   - Medical conditions
   - Last donation date

3. Tap "Update Medical Info"

**Note:** Blood group changes require admin verification and medical documentation.

### 5.4 Availability Settings

**Setting Donation Availability:**
1. Profile → Availability
2. Toggle "Available for Donation" switch
3. Set availability preferences:
   - Immediate availability
   - Schedule preferred times
   - Maximum distance willing to travel
   - Preferred donation centers

### 5.5 Privacy Settings

1. Profile → Settings → Privacy
2. Configure:
   - Who can see your profile
   - Who can contact you
   - Show location on map (Yes/No)
   - Hide phone number
   - Anonymous donation mode

## 6. Blood Test Records

### 6.1 Uploading Blood Test Results

**Step-by-step Guide:**

1. Navigate to Profile → Blood Tests
2. Tap "+ Add New Test Result"
3. Fill in test information:
   - Test date
   - Testing laboratory name
   - Test type (Complete Blood Count, Blood Group, etc.)

4. Upload test document:
   - Tap "Upload Document"
   - Choose from Camera or Gallery
   - Select image/PDF of test result

5. Enter test values (if applicable):
   - Hemoglobin level
   - Blood group confirmation
   - Other relevant values

6. Tap "Submit for Verification"

### 6.2 Viewing Test History

1. Profile → Blood Tests
2. View list of all uploaded tests:
   - Date of test
   - Test type
   - Verification status
   - Download/View option

3. Tap any test to view details
4. Download test report by tapping download icon

### 6.3 Test Verification Status

Tests can have three statuses:
- **Pending** ⏳: Awaiting admin verification
- **Verified** ✓: Approved by admin
- **Rejected** ✗: Requires resubmission

## 7. Donor Map & Search

### 7.1 Finding Donors on Map

**Using the Interactive Map:**

1. Tap **Map** icon in bottom navigation
2. The map displays:
   - Your current location (blue marker)
   - Available donors (red markers)
   - Blood banks (green markers)

3. **Map Controls:**
   - Pinch to zoom in/out
   - Drag to pan around
   - Tap location button to center on you

### 7.2 Filtering Donors

**Apply Search Filters:**

1. Tap the filter icon on map screen
2. Set filters:
   - **Blood Group**: Select required blood type
   - **Distance**: Set radius (1km - 50km)
   - **Availability**: Currently available only
   - **Verification Status**: Verified donors only

3. Tap "Apply Filters"
4. Map updates to show matching donors

### 7.3 Viewing Donor Profiles

1. Tap any donor marker on map
2. Info card displays:
   - Donor name
   - Blood group
   - Distance from you
   - Last donation date
   - Verification badge

3. Tap "View Profile" for full details
4. Options available:
   - Send donation request
   - Call donor (if phone visible)
   - Get directions

### 7.4 Sending Donation Request

**From Map:**
1. Select donor profile
2. Tap "Request Donation"
3. Fill in request form:
   - Urgency level (Emergency/Urgent/Normal)
   - Required units
   - Hospital/Location
   - Additional notes
   - Contact information

4. Tap "Send Request"
5. Donor receives notification

**Direct Request:**
1. Home → Request Blood
2. Select blood group needed
3. Enter location
4. System finds matching donors
5. Send request to one or multiple donors

## 10. Troubleshooting

### 10.1 Common Issues & Solutions

#### Cannot Login
**Problem:** "Invalid credentials" error
**Solutions:**
- Verify email address is correct
- Check Caps Lock is off
- Try "Forgot Password" to reset
- Clear app cache: Settings → Storage → Clear Cache
- Ensure internet connection is stable

#### Profile Not Updating
**Problem:** Changes not saving
**Solutions:**
- Check all required fields are filled
- Ensure internet connection is stable
- Try logging out and back in
- Contact support if issue persists

#### Map Not Loading
**Problem:** Map screen is blank
**Solutions:**
- Check location permissions: Settings → Permissions → Location
- Enable GPS/Location services on device
- Check internet connection
- Restart the app

#### Cannot Upload Documents
**Problem:** Upload fails or document not accepted
**Solutions:**
- Ensure file size is under 5MB
- Use JPG, PNG, or PDF format only
- Check camera/storage permissions
- Try reducing image quality

#### Not Receiving Notifications
**Problem:** Missing donation requests or updates
**Solutions:**
- Check notification permissions: Settings → Notifications
- Enable push notifications in app settings
- Check device's Do Not Disturb mode
- Reinstall the app if needed

### 10.2 Error Messages

| Error Code | Message | Solution |
|------------|---------|----------|
| AUTH-001 | Authentication failed | Re-login with correct credentials |
| NET-001 | Network error | Check internet connection |
| PERM-001 | Permission denied | Grant required permissions in settings |
| DOC-001 | Invalid document format | Use JPG, PNG, or PDF only |
| VERIFY-001 | Verification pending | Wait for admin approval |

### 10.3 Performance Issues

**App Running Slowly:**
- Close background apps
- Clear app cache
- Restart device
- Update to latest version
- Check available storage space

**Battery Draining Fast:**
- Disable constant location tracking
- Reduce map usage
- Lower screen brightness
- Turn off unused notifications

## 11. FAQs

### Account & Registration

**Q: How do I create an account?**
A: Tap "Sign Up" on the welcome screen, fill in your details including blood group, verify your email, and complete registration.

**Q: Can I change my blood group after registration?**
A: Yes, but it requires admin verification and upload of valid blood test report showing your blood group.

**Q: Is my personal information secure?**
A: Yes, all data is encrypted and stored securely. You can control privacy settings from your profile.

### Donations

**Q: How often can I donate blood?**
A: Men can donate every 3 months, women every 4 months. The app tracks this automatically and shows your next eligible date.

**Q: Who can see my donation availability?**
A: Only verified users in your configured search radius can see you're available, based on your privacy settings.

**Q: Can I donate to specific people only?**
A: Yes, you can set your profile to private and only respond to direct requests.

### Requests

**Q: How do I request blood in an emergency?**
A: Tap "Request Blood" on home screen, select blood group, mark as emergency, and the system will notify all compatible donors nearby.

**Q: What if no donors respond to my request?**
A: The app will expand the search radius and notify nearby blood banks. You can also manually contact donors from the map.

### Verification

**Q: Why does my account need verification?**
A: Verification ensures authenticity and safety. Verified accounts are more trusted by other users.

**Q: How long does verification take?**
A: Usually 24-48 hours. Upload clear documents for faster processing.

**Q: What documents do I need for verification?**
A: Government-issued ID and a recent blood test report showing your blood group.

### Privacy & Safety

**Q: Can I hide my location?**
A: Yes, go to Profile → Privacy → Hide Location. Your profile will still be visible in searches but without exact location.

**Q: How do I report suspicious activity?**
A: Tap the three dots on any profile and select "Report User". Provide details and submit.

**Q: Can I block certain users?**
A: Yes, go to their profile → Block User. They won't be able to contact you or view your profile.

### Technical

**Q: The app keeps crashing, what should I do?**
A: Update to the latest version, clear cache, restart device. If issue persists, contact support with your device details.

**Q: Can I use the app without internet?**
A: Limited functionality only. You can view your profile and history offline, but cannot search donors or send requests.

**Q: Is the app available in multiple languages?**
A: Currently available in English. More languages coming soon.

## Appendix A: Blood Donation Eligibility

### General Requirements
- Age: 18-65 years
- Weight: Minimum 50kg
- Healthy with no infections
- Not donated in last 3-4 months

### Temporary Deferrals
- Recent tattoo/piercing: Wait 6 months
- Dental procedure: Wait 24 hours
- Vaccination: Wait 2-4 weeks (depends on vaccine)
- Pregnancy/Breastfeeding: Wait 6 months after delivery

### Permanent Deferrals
- HIV/AIDS
- Hepatitis B or C
- Heart disease
- Certain cancers
(Consult with medical professionals for complete list)

## Appendix B: Blood Type Compatibility Chart

### Who Can Donate to Whom

| Recipient | Compatible Donors |
|-----------|-------------------|
| O- | O- |
| O+ | O-, O+ |
| A- | O-, A- |
| A+ | O-, O+, A-, A+ |
| B- | O-, B- |
| B+ | O-, O+, B-, B+ |
| AB- | O-, A-, B-, AB- |
| AB+ | All blood types |

### Universal Donor & Recipient
- **Universal Donor**: O- (can donate to all)
- **Universal Recipient**: AB+ (can receive from all)

## Appendix C: Glossary

- **Donor**: Person who gives blood
- **Recipient**: Person who receives blood
- **Unit**: Standard blood donation amount (approximately 450ml)
- **Verification**: Admin approval of user account or document
- **Hemoglobin**: Protein in red blood cells carrying oxygen
- **Apheresis**: Donation of specific blood components
- **Whole Blood**: Complete blood donation including all components
- **Plasma**: Liquid portion of blood
- **Platelets**: Blood cells helping in clotting
